# VOID 2471 — Releases

Repositório oficial de distribuição das versões públicas de **VOID 2471**.

Este repositório contém apenas arquivos de release, instaladores e pacotes de distribuição do jogo.

O código-fonte de **VOID 2471** não está disponível neste repositório.

## Plataformas

* Windows x64
* Android
* Web

## Windows

Para instalar no Windows:

1. Acesse a versão mais recente em **Releases**.
2. Baixe o arquivo:

```text
VOID-2471-Setup.exe
```

3. Execute o instalador.
4. Conclua a instalação.
5. Abra **VOID 2471** pelo Menu Iniciar ou pelo atalho criado durante a instalação.

## Versões

O projeto utiliza versionamento semântico:

```text
MAJOR.MINOR.PATCH
```

Exemplos:

```text
0.1.0
0.1.1
0.2.0
1.0.0
```

Enquanto o jogo estiver em desenvolvimento, versões podem ser publicadas como **Pre-release**.
